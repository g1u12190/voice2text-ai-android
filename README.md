# Voice2Text AI

## Descripción

Voice2Text AI es una aplicación web diseñada para convertir la voz en texto de manera inteligente.

El objetivo es facilitar la creación de mensajes para WhatsApp, correos electrónicos, documentos y cualquier plataforma donde sea necesario escribir.

---

## Características (MVP)

- Dictado por voz.
- Copiar texto.
- Limpiar texto.
- Interfaz adaptable.
- Compatible con dispositivos móviles.

---

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Web Speech API
